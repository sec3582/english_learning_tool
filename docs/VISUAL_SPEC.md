# VISUAL_SPEC.md — 沉浸式文本小說 · 夜模式視覺規格

**參考美學**：《香水：一個謀殺犯的故事》(Perfume: The Story of a Murderer, 2006) — 導演 Tom Tykwer
**範圍**：v2 新功能「沉浸式文本小說」專用的深色視覺系統
**與現有系統的關係**：本規格是**獨立並存**的第二套視覺系統，不取代 `decisions.md` / `storyboard.md` / `compiled-spec.md` 所定義的暖色 Day Mode。Day Mode 是「格拉斯作坊的白天」；本規格是「主角失去嗅覺後，獨自背單字的夜晚」。兩者共用一條原則——**禁止純黑、純白、任何飽和鮮豔色**——但色相走向完全相反：Day Mode 全站是暖色，本規格全站以冷色為主，暖色被降級為稀有的敘事事件，而非背景基調。
**日期**：2026-07-05

---

## 0. 一句話 Brief

> 主角活在一座沒有溫度的港口城市裡，靠背單字確認自己還在運作；只有當劇情把他拉回「教會／政客」的公開場合，世界才會短暫地被燭光燙傷。

## 1. 情緒板描述（Mood Board in Text）

### 1.1 電影場景參考

**場景 A — 巴黎魚市的清晨霧氣（開場，冷調主世界）**
Grenouille 出生那一幕，天還沒亮，攤販的呼吸在冷空氣裡凝結成白霧，魚市的石板地是濕的鉛灰色，沒有任何暖光源，唯一的光是快要破曉的冷藍天色。這是主角背單字時「日常」的視覺基準——沒有戲劇性，只有一種被凍住的存活感。**對應網頁元素**：預設背景層（Suminagashi 墨流）與所有非敘事事件狀態下的 UI 底色。

**場景 B — Baldini 香水鋪深夜製香（谷底時刻，唯一暖色入侵）**
Baldini 在打烊後的作坊裡，用一盞油燈照著配方書，燈芯的暖光只照亮桌面直徑不到一公尺的範圍，四周仍是深色。這不是「溫暖」的場景，是「被單一光源審問」的場景——光線越集中，陰影裡藏的東西越可疑。**對應網頁元素**：Day 14 谷底瞬間——傷口色 `#8a3b2c` 的介入方式，必須是「一小塊被照亮的證據」，不是整體換色。

**場景 C — 格拉斯大教堂廣場的公開處決（教會／政客場景，暖調敘事段落）**
群眾聚集在教堂前的廣場，火把與燭光把石造建築染成一片搖曳的暗金色，人群的臉在火光下顯得既虔誠又危險。這是「集體、被觀看、表演性」的暖色語境，與主角私下背單字的孤獨冷色形成對照。**對應網頁元素**：政客／教會敘事場景整段的專屬暖色系統。

### 1.2 視覺關鍵字

| 關鍵字 | 網頁對應元素 |
|---|---|
| **凍結的呼吸**（冷、凝結、靜止） | 主世界背景色階、Suminagashi 墨流的預設冷灰調色盤、所有非敘事狀態下的動畫速度上限 |
| **孤光審問**（單一光源、被迫聚焦） | Day 14 傷口色的呈現方式——只照亮單一卡片，不擴散到其他 UI |

## 2. 色彩規格

### 2.1 主世界·冷調系統（預設狀態，約佔畫面時間 85–90%）

| Token | HEX | 用途 | 使用比例 |
|---|---|---|---|
| `--cold-void` | `#14171a` | 全站底色（霧黑，非純黑；帶極淡藍灰） | 65% |
| `--cold-wash` | `#1b1f23` | 次層墨色、Liquid Glass 卡片底層陰影 | 15% |
| `--cold-parchment` | `#d6dbe0` | 主要文字（冷灰白，非純白） | 12% |
| `--cold-dim` | `#838d96` | 次要文字、說明文字 | 5% |
| `--cold-accent` | `#5c7686` | 唯一允許的冷調強調色（互動狀態、連結、進行中指示）——低飽和青灰藍，禁止提高飽和度 | 2.5% |
| `--glass-cold-fill` | `rgba(214,219,224,0.05)` | 冷調 Liquid Glass 卡片填色 | — |
| `--glass-cold-border` | `rgba(92,118,134,0.20)` | 冷調 Liquid Glass 卡片邊緣 | — |

**禁止事項**：此系統中不得出現任何暖色系裝飾（不可為了「活潑」加一點暖黃強調鈕）。若某個 UI 元件想用暖色吸引注意力，答案永遠是「不要」，改用 `--cold-accent` 的亮度變化，或留白處理。

### 2.2 教會／政客場景·暖調系統（稀有敘事事件，約佔畫面時間 10–15%）

| Token | HEX | 用途 | 使用比例 |
|---|---|---|---|
| `--warm-void` | `#241a12` | 場景底色（燭光暗底，非純黑；帶暖棕） | 60% |
| `--warm-parchment` | `#e8dcc8` | 主要文字（羊皮紙白，非純白） | 18% |
| `--warm-gold` | `#a8792e` | 暗金強調（火把、燭光反射、標題底線） | 15% |
| `--warm-dim` | `#8c7355` | 次要文字 | 5% |
| `--glass-warm-fill` | `rgba(232,220,200,0.06)` | 暖調 Liquid Glass 卡片填色 | — |
| `--glass-warm-border` | `rgba(168,121,46,0.24)` | 暖調 Liquid Glass 卡片邊緣 | — |

### 2.3 傷口色（不屬於任一系統，全站僅出現一次）

| Token | HEX | 使用規則 |
|---|---|---|
| `--wound` | `#8a3b2c` | **只能在 Day 14 谷底事件使用一次。** 不放進任何元件庫、不做成可重複調用的 CSS class，寫死在該事件專屬的樣式區塊裡，避免未來被誤用或「順手」拿去當警示色。用完即封存。 |

### 2.4 兩套色系的切換規則

1. **觸發時機**：由劇情狀態機決定（例如「進入教會場景」的敘事節點），不是使用者手動切換的主題設定。
2. **切換方式**：`--cold-*` 與 `--warm-*` 兩組 token 各自完整定義在獨立的 CSS class（`.scene-cold` / `.scene-warm`），套用在最外層容器，禁止在同一個畫面裡混用兩組 token。
3. **墨流色相是否跟著轉暖**：**要**。Suminagashi 背景不是「換一張圖」，是同一套粒子系統改變色相參數——冷調時墨滴帶青灰／靛藍色相，暖調時同一組粒子改用琥珀／赭石色相。色相改變本身就是場景切換的主要視覺語言，而不是靠疊加濾鏡。
4. **過場動畫**：色相與底色以 2.5–3 秒的緩慢 crossfade 過渡（見第 3 節動畫規格），期間墨流的擴散速度暫時降到平常的 40%，模擬「世界屏住呼吸換氣」的感覺。過場中不得出現硬切、閃爍或任何鏡頭式轉場（劃接、遮罩），一律是顏色本身的漸變。

## 3. 動畫規格

### 3.1 通則（全站適用）

- **緩動曲線**：一律使用具重量感的 ease-in-out（近似 `cubic-bezier(0.45, 0, 0.15, 1)`），沒有任何 overshoot／bounce／彈簧曲線。速度變化要「像液體」，不是「像按鈕」。
- **速度上限**：冷調主世界的任何動畫，時長下限 350ms，不做「即時反饋」式的 100–150ms 快閃動效——一切都刻意慢半拍，像是隔著一層水在動作。
- Suminagashi 墨流：p5.js 實作，粒子/墨滴以 Perlin noise 驅動緩慢漂移，冷調狀態下擴散速度極慢（單滴墨完全暈開需 25–40 秒），營造凍結感。

### 3.2 Day 0 → Day 1：刻意的平板重複（開場麻木感）

- 前面每一張單字卡的翻卡動畫，時長、緩動曲線、旋轉角度、陰影變化**必須逐字逐句完全相同**——不做任何隨機化或微變化（不加入常見的「輕微隨機延遲讓畫面有生氣」的手法，這裡刻意反其道而行）。
- 背景 Suminagashi 墨流在這個階段只用單一冷灰墨色，擴散速度、粒子數量固定不變。
- **複習到 "empty" 卡片時**：這是全曲線第一個視覺事件。墨流背景出現**一滴異色的墨**——建議用一個帶極輕微暖棕／鏽色的墨滴（例如色相稍微偏向 `--wound` 但飽和度壓到極低，不能讓玩家一眼認出這是「伏筆」），從畫面隨機一角落緩慢滴入，暈開速度比平常慢（35–45 秒），且**暈開後不會完全消失**——留下一絲比背景稍深一階的痕跡，永久疊加進墨流的雜訊紋理裡，之後每一幀畫面都帶著這個看不明顯但存在的污漬。

### 3.3 Day 14：唯一的傷口色事件（谷底）

- 玩家觸發真相揭露的操作（例如拖曳排序兩個酒杯，而非單純點擊選項）完成的瞬間：
  1. 背景 Suminagashi 墨流**暫停擴散** 1.5–2 秒（動態上的停頓＝敘事上的屏息）。
  2. 觸發卡片本身的 Liquid Glass 邊框由 `--cold-accent` 轉為 `--wound`，轉色時間拉長到 1.2 秒（比通則的 350ms 慢超過三倍，強調「這不是一般互動」）。
  3. `--wound` 以極小範圍的放射狀暈染從卡片中心擴散，半徑不超過該卡片本身，**絕不擴散到卡片以外的 UI 或背景墨流**——這是「孤光審問」的具體實作：只有一個東西被照亮，其餘一切維持原本的冷調暗處。
  4. 事件結束後，墨流恢復擴散，但速度只回復到原速的 70%，維持 8–10 秒後才完全恢復——谷底之後，世界不會立刻若無其事地繼續轉動。
  5. 該卡片此後永久保留一條髮絲寬的 `--wound` 邊線（唯一例外），作為「這件事發生過」的視覺傷疤；其他任何卡片、任何時候都不得再出現這個顏色。

### 3.4 Day 30：安靜的離場（不歸零，但也不慶祝）

- 離場畫面的動畫節奏必須刻意呼應 Day 0 開場：翻卡速度、緩動曲線、墨流擴散速度都回到開場時的設定值——**視覺上的「首尾呼應」本身就是敘事**（一切好像回到原點，但玩家知道不是）。
- **明確禁止**：彩帶／粒子噴發、成就徽章的彈跳或發光登場、任何上升音階的音效觸發動畫、進度條「填滿到 100%」的慶祝式動效。
- 唯一允許的差異：畫面在最後多停留 1.5 秒的靜止（比平常任何一次翻卡後的停頓都長），讓玩家「多留一下」，而不是被導向下一個任務。

## 4. 排版與字體建議

- **中文標題字體**：思源宋體／Noto Serif TC 或系統對應細明體，字重維持在 Regular 至 Medium 之間，**不使用 Bold**——粗體在這套美學裡讀起來太有主張、太像宣告，這個角色不宣告任何事。
- **英文標題／單字本體字體**：細襯線（如 EB Garamond、Cormorant 風格），字距略微放寬（+0.02em），模擬活字印刷版壓痕的疏離感。
- **內文／UI 功能文字**：系統無襯線字體（-apple-system / PingFang TC / Microsoft JhengHei 堆疊），行高 1.8–2.0，字距不特別放寬——功能性文字要保持易讀，不需要參與情緒表演。
- **留白比例**：每個畫面只允許一個視覺焦點（見核心原則），因此留白必須佔畫面至少 55–60%。單字卡本身可以精緻，但四周留白要多到讓卡片「浮」在墨流上，而不是被其他 UI 元件包圍擠壓。
- **數字（複習天數、正確率等）**：一律使用 tabular-nums，避免統計數字排列時因等寬與否而抖動。

## 5. 各頁面視覺重點

### 5.1 首頁（匯入文章）

**唯一視覺焦點**：文章輸入區——一張浮在冷調墨流上的 Liquid Glass 卡片，沒有其他次要 CTA 或裝飾元件分散注意力。頁面載入時墨流以最慢速度運行，模擬「使用者還沒開始，世界靜止著等他」。不放置任何歡迎詞、吉祥物、或行銷式標語——這裡的沈默本身就是語氣。

### 5.2 單字練習頁（填空、抽卡）

**唯一視覺焦點**：當前這一張卡片。填空模式與抽卡模式共用同一套翻卡/顯示動畫節奏（見第 3 節），確保 Day 0→30 的整條體驗曲線可以在這個頁面完整發生。此頁是全站唯一可能觸發「教會／政客」暖色場景切換的頁面（透過特定劇情節點的敘事卡片觸發），其餘頁面不承載場景切換邏輯。傷口色事件（3.3）僅在此頁面的特定卡片上發生一次。

### 5.3 學習成果頁（進度／統計視覺化）

**唯一視覺焦點**：一個以「墨的累積濃度」呈現學習量的視覺化圖形，而不是傳統遊戲化的徽章牆或進度條——複習越多次的字，對應區域的墨色越深、紋理越厚，具現化「記憶被反覆浸泡」的意象。此頁必須遵守 Day 30 訂下的「無慶祝式 UI」原則並推廣到全站：任何統計數字的呈現都不使用上升動畫搭配歡快音效，改用緩慢的墨色沉澱動畫表達累積感。

## 核心原則重申

- 寧可少，不要多：每個頁面只有一個視覺焦點。
- 功能服從美學：若某個功能性需求（例如想加一個「連續複習天數」的火焰圖示）會破壞冷調孤獨感，選擇隱藏或用墨色濃度取代，而不是妥協加入不屬於這套色系的暖色裝飾。
- 傷口色 `#8a3b2c` 全站僅此一次——這條規則的存在理由，就是為了讓它出現的那一刻真正有重量。
